联系弹窗的联系群卡只有居中的「DSH 插件交流群」标题，飞书/QQ/微信三张卡视觉上完全一样；README 靠表头文字区分渠道，弹窗没有表头。owner 2026-11-01 观感反馈要求卡片名前加**渠道官方 LOGO**，拍板方案 B（彩色品牌徽章 18px），并明确要求「以后增加渠道时能轻易增加这个 logo」。本票专门做这次开发。

## 背景

## 交付
1. **渠道标识表**：新增 client 模块（建议 `packages/base/src/client/channel-badges.ts`），一条渠道 = 一个表项（品牌色 + 官方标志 SVG path + 渠道名）；新增渠道只加数据、不改渲染逻辑；未知 platform 静默不渲染徽章。
2. **群卡标题行**：h3 内渲染 18px 彩色圆角徽章 + 群名，徽章 `aria-hidden="true"`，群名可见文本保持原样；新增 `.dsh-base-modal__card-badge` 样式（主题化、居中、与 13px 文案基线对齐）。
3. **微信卡副标题去重**：删除 `contact/groups.json` 中 wechat 的 `subtitle`（「群聊：DSH 插件交流群」与标题重复），渠道名并入无障碍名；`revision` +1、`updatedAt` 更新，跑 `npm run build:data` 同步 `data/manifest.json` 与 `src/core/baseline.ts`。
4. **文档**：`GLOSSARY.md`（群卡片 / 群名 / 群号与组织 / 联系弹窗 / 群组条目）+ `docs/base包与联系弹窗-方案.md` 的群卡描述更新。
5. **测试**：渠道表完整性（当前每个 platform 都有徽章且色值/path 合法）、渲染（已知平台出徽章且在群名文本前、未知平台不出）、微信卡无副标题、`npm run data:check` 通过。
