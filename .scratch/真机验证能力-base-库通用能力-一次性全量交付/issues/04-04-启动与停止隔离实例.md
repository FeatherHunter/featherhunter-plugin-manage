# 04: 04 启动与停止隔离实例

**What to build:** `dsh-verify launch` 能在隔离环境里起一个 DSH 实例：复制目标 profile 到隔离 home（清掉复制来的日志缓存）、独立 `DSH_HOME`/`USERPROFILE`/启动目录三件套、detached 启动、等 ready、写 `instance.json`（端口、token URL、pid、日志落点、注入的变量名、模型来源）。ready 必须两条判据并用：启动 stdout 那一行 token URL，且宿主插件清单的 fiber 状态全部 active；端口能连、日志有行都不算 ready。`stop` 杀进程树并验证消失（留 `stopped.json`），失败要报清哪个 pid 没死。`--dry-run` 打印真实启动计划（argv、注入的环境变量名、日志落点、模型来源），不含任何密钥值。
