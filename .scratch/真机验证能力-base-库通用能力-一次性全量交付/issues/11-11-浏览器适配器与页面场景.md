# 11: 11 浏览器适配器与页面场景

**What to build:** 页面级验证靠插件仓注入的浏览器适配器，核心不依赖任何浏览器库：适配器缺失时页面类检查记 `blocked`（说明缺适配器、怎么注入），绝不记 `fail`。给出一个可用的参考适配器（headless chromium），能开实例页面、取尺寸、抓截图、收集 pageErrors；全屏一律用 CDP 设置窗口态，禁止用 `setViewportSize` 假装全屏（历史上这样误判过产品缺陷）。页面检查产出截图与尺寸证据，空间类结论必须附当次视口字段。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 注入适配器时页面检查通过；不注入时同一检查变 `blocked` 且退出码为 2
- [ ] 全屏判定用真实窗口尺寸，尺寸不符时报「期望 vs 实际」
- [ ] 截图证据落盘并进清单（含字节数与 sha256）
- [ ] 参考适配器不在核心包里 import，核心包构建后不含任何浏览器依赖
