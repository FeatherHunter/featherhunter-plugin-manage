# 07: 07 证据归档与校验

**What to build:** 证据不能只存在「这一批的目录里」：`dsh-verify evidence archive` 把整批证据复制到归档根下 `<批次名>-<时间戳>/`，并写按路径排序的 `SHA256SUMS.txt`；`dsh-verify evidence verify` 重算归档内每个文件的哈希，能报出被改、缺失、多余、格式坏死四类差异。同批证据同名文件加序号后缀绝不覆盖；证据清单里的候选身份字段只能由命令层注入，不能被 `--extra` 覆盖。
