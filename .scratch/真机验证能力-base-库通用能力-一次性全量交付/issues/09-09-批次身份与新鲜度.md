# 09: 09 批次身份与新鲜度

**What to build:** 给每次验证开一条可复核的身份链：`batch open` 记录本地基线（ref、tip、目标版本）与批次记录，打印身份行与基线行（逐字格式，生成与解析互为逆运算）；`batch status` 做新鲜度双判据 —— HEAD 未移动**且**基线 ref 当前 tip 未前进，基线不可读也判失效（不可读 ≠ 没前进）；显式允许过期基线时必须在报告里注明。证据入账时做三重绑定（批次名、提交、候选 manifest sha256），任一不符不得进统计。
