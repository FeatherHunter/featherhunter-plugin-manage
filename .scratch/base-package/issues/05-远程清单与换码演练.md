# 05: 远程清单与换码演练

**What to build:** 给弹窗接上远程清单：打开时先用内置基线立即渲染，同时并行拉远端清单；按 unpkg → npmmirror → jsDelivr 顺序回退，单次超时 1500ms、不重试、会话内缓存 30 分钟；校验通过后换上新微信卡并按真实日期生成有效期文案。失败、非法 JSON、空 groups、结构越界一律降级为基线。随后做一次真实换码演练：发布含新微码的版本，用同一份客户端代码验证拉到新清单与新图片。
