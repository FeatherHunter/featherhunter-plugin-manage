# 04: 联系弹窗

**What to build:** 客户端导出联系弹窗能力：一个动作行控件（按钮形态）与零参调用即用的弹窗。弹窗用原生 `<dialog>.showModal()` 进入 top layer，内部按群组渲染卡片：上限 4 列、窄屏降列、每卡含标题/副标题/二维码/角注；顶部有「扫描二维码加入我们」提示；关闭方式覆盖 Esc、遮罩、关闭按钮，关闭后焦点回归、滚动解锁；移动端给群号可点击复制；中英文案按显式参数 > 宿主语言 > 浏览器语言 > 中文的回退链；微信码缺失或过期时降级为链接，绝不展示过期码。
