# 01: 页头操作组四方向原型与方向拍板

**What to build:** 在同一设置面板页头的真实上下文里，做个能直接打开的原型单页（?v= 参数 + 底部浮条切换），给出四个方向差距尽量大的操作组方案。每个方向都要有浅色/深色、默认/hover/active/focus/disabled、3 个按钮和加第 4 个按钮/溢出场景，并同页放一个「容器整体响应 hover」的反例做对照；每个方向标注代价与适用场景。用户看完选定一个方向，并同时拍板三项口径：Issue 落点（仓库 issues 列表 vs issues/new）、按钮尺寸（统一 16 还是 deck 保留 18）、是否保留页头 + 底部双联系入口。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 四个方向可在同一页面切换，浅色与深色均可见，hover/focus/溢出可交互
- [ ] 每个方向有代价说明与反例对照
- [ ] 用户选定的方向与三项口径写入本票结论区
- [ ] 原型按原型规范提交到临时分支/可回看位置，票面留指针
