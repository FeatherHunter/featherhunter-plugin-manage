## Problem Statement

调色板仓首页只有静态主题截图与三步文字指令，动态操作（换肤一键点击、37 色联动调色、字体字号切换、自定义主题增改删、AI 编辑）没有可看的演示。英文页同样缺这一块。7 段操作视频已录好，但首页没有独立章节收纳它们，更没有“默认折叠、点开才看”的呈现。

## Solution

在调色板仓首页新增独立章节“基础使用演示”（英文 mirror 为 Basic usage demo），默认折叠。章节内用一层外层折叠包 7 条内层折叠，每条收纳一段操作视频：标题行加一句话说明加视频加裸链接兜底加 2~4 步文字兜底。章节落在安装章之后、功能章之前，中英文各写一份、复用同一批视频地址，尾部联系区块与现有门禁原样不动。本规格落在管理仓，实施落在调色板仓。

## User Stories

1. As a 新读者， I want a 在首页看到一个默认折叠的“基础使用演示”章， so that 首屏不被 7 个视频撑长，想看才点开。
2. As a 只想装插件的读者， I want a 点开第一条就看到安装演示， so that 跟着视频一次装好并重启生效。
3. As a 想调字体的读者， I want a 在第二条看到字体与字号切换演示， so that 知道等宽与常规的区别和字号范围。
4. As a 想换肤的读者， I want a 在第三条看到选择主题演示， so that 一键挑到喜欢的主题。
5. As a 想做专属胶囊的读者， I want a 在第四条看到新增自定义主题演示， so that 知道 37 个槽位怎么调、预览怎么联动、存到哪里。
6. As a 已有胶囊的读者， I want a 在第五条看到编辑自定义主题演示， so that 回来改色不迷路。
7. As a 不想要的胶囊的读者， I want a 在第六条看到删除自定义主题演示， so that 敢删且知道后果。
8. As a 想偷懒的读者， I want a 在第七条看到 AI 编辑自定义主题演示， so that 知道一句话让 AI 改色。
9. As a 弱网或代理环境读者， I want a 每条视频下方都有一行可点的裸链接加文字步骤， so that 播放器空白时仍能复制外开或照文字做。
10. As a 手机读者， I want a 7 条默认都闭合、点哪条开哪条， so that 不一次加载 7 个视频、流量可控。
11. As a 英文读者， I want a 在英文页同位看到语义对齐的演示章、视频复用同一批， so that 不用切回中文页找视频。
12. As a 关键词搜索者， I want a 每条有标题行与一句话说明， so that 站内搜“删除自定义主题”能命中。
13. As a 贡献者， I want a 新增演示只加一条同构内层折叠、不改外层结构， so that 加第 8 段不重构整章。
14. As a 维护者， I want a 演示章不动尾部联系区块与星标曲线， so that 全仓统一规范与现有门禁不被误触。
15. As a 发版者， I want a 版本号同步与构建产物派生不受演示章影响， so that 发版流程零改动。
16. As a 市场或包页读者， I want a 即使折叠与播放器被剥离仍能看到裸链接， so that 至少有点可点。

## Implementation Decisions

- 章节独立：新章只收 7 段演示，不复用安装文字与静态种草图的内容；标题中文锁“基础使用演示”、英文锁“Basic usage demo”，小标锁“DEMO”。
- 落点：中文页与英文页都在安装章之后、功能章之前插入；展示标记区间、感谢表格标记区间、尾部联系区块原样保留，不在其后追加。
- 折叠形态：外层一折叠包 7 条内层折叠，全部默认闭合；内层 7 条平铺、不分组；折叠标签只写单行纯文本。
- 条目结构：每条按标题行加一句话说明加主展示播放器加裸链接兜底加两到四步文字兜底组织，7 段依次为安装插件、设置字体字号、选择主题、新增自定义主题、编辑自定义主题、删除自定义主题、AI 编辑自定义主题。
- 视频承载：播放器地址与裸链接用同一批托管地址；只声明播放控制，不声明自动播放与循环；视频资产不入库；附件挂靠专用素材主题、正文注明勿删。
- 中英文同步：两页各写一份，视频地址复用同一批，标题、说明、折叠标签语义对齐；首版英文页可复用中文录制的视频，若含中文旁白或字幕则加一句英文注并立项后续重录。
- 构建产物：包内副本永不手改，随英文页派生，演示章随派生自动带入。
- 术语：“基础使用演示”指本章 7 段；“折叠”指外层加内层结构；与现有词汇无冲突。
- 例外留痕：用户拍板用嵌套，尽管研究报告主张单层单个；本规格以用户拍板为准，风险由裸链接兜底与移动端验收对冲。

## Testing Decisions

- 好测试只看外部行为：读两页文档当纯文本断字符串与数量，不渲染、不联网、不解码视频。
- 缝只用一个、沿用最高缝：文档纯文本缝（既有主体测试与头尾测试与星标门禁同一路子）。不新增代码缝。
- 必测项：外层默认闭合、内层恰好 7 条且标题一一对应、每条含播放器声明与裸链接、标签单行纯文本、无自动播放、视频无入库、英文同位对齐、尾部联系区块与星标引用原样、版本号与感谢表格门禁仍绿。
- 参照物：以 #155 资产票的 7 段为输入基准，以折叠研究报告为写法基准。
- 不测项：视频码值解码目标、播放器像素样式、徽章、曲线数据。

## Out of Scope

- 不改静态展示网格与安装文字，不重写功能表与升级指令。
- 首版不重录英文视频，不做封面图跳转与自动播放。
- 不把视频文件入库，不改同步版本号与星标曲线的脚本与门禁。
- 不修市场与包页剥离标签的行为，只做裸链接保底。
- 不碰功能代码、设置面板、技能逻辑，只动两页文档演示章。
